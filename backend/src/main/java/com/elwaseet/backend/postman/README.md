# Elwaseet API - Postman Collections

## Setup Instructions:

### Import Collections:
```bash
git pull
```
Open Postman → Import → Select all `.json` files from `postman/` folder

## Collections Overview:
- **ElWaseet Auth API** - Login/Register/Verify
- **ElWaseet Browse Jobs** - Provider browsing jobs
- **ElWaseet Create Job** - Customer creating jobs
- **ElWaseet Delete Service/Profile Photo** - Provider profile
- **ElWaseet Accept Application** - Customer accepting applications
- **ElWaseet Job Applications System** - Application management
- **ElWaseet Provider Profile** - Provider CRUD
- **ElWaseet Review System** - Reviews & ratings
- **ElWaseet Update Job** - Job modifications
- **ElWaseet Get Job** - Job details
- **Elwaseet Browse Provider** - Browse providers
- **ElWaseet Escrow Core** - Payment/escrow
- **ElWaseet Escrow Integration** - Escrow workflows

## Notes: 
- ⚠️ Don't edit and re-commit collections
- ✅ Pull latest before testing: `git pull`
- 🔑 Each request needs JWT token in Authorization header
